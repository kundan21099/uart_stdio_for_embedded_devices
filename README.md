### UART STDIO

***Description***
This code can be used similar as standard printf and scanf function, for differentiation the functions names are printk and scank.
This code was originally developed for STM32 in 2022 and it is compatible with STM32 where it has UART hardwre buffer of size 1.

The dafault generated name  i.e. **USART1 / USART2** is being used, make sure to change this name in print.c if not same as default.
